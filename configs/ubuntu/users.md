# Linux User Administration

## User Management

Performed Linux administration tasks including:

- User management
- Group management
- File ownership
- File permissions
- sudo administration

## Common Operations

```bash
sudo adduser username
sudo usermod -aG sudo username
groups
id
passwd
```

## Permissions

Configured Linux permissions using:

- chmod
- chown
- chgrp

Applied the principle of least privilege when assigning permissions.
