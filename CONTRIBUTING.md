# Contributing Guide

Thank you for your interest in this Cisco & Linux Homelab project.

This repository documents a personal enterprise networking and Linux infrastructure lab built for learning, experimentation, and portfolio development.

## Project Goals

* Learn Linux System Administration
* Learn Cisco Networking
* Practice Infrastructure Automation
* Follow Enterprise Best Practices
* Document all configurations and implementations

## Repository Structure

* `automation/` – Python automation scripts
* `configs/` – Device configurations and command outputs
* `docs/` – Architecture and implementation documentation
* `runbooks/` – Operational procedures
* `monitoring/` – Monitoring documentation
* `scripts/` – Linux administration scripts
* `diagrams/` – Network diagrams
* `screenshots/` – Verification screenshots

## Contribution Guidelines

If contributing to this project:

* Keep documentation clear and concise.
* Follow existing folder organization.
* Remove all sensitive information before committing.
* Test scripts before submitting changes.
* Write meaningful commit messages.

## Documentation Standards

Each implementation should include:

* Purpose
* Configuration
* Verification
* Troubleshooting
* References (if applicable)

## Commit Message Examples

* Add VLAN documentation
* Configure SSH hardening
* Improve Nginx runbook
* Add Python backup automation
* Update monitoring documentation

Thank you for helping improve this project.
