# Cisco/Linux Home Lab

Enterprise-style networking and Linux systems administration home lab built using a Cisco Catalyst 2960X switch and Ubuntu Server.

## Features

- Cisco Catalyst 2960X switch administration
- Secure SSH remote management
- USB console (out-of-band) management
- Ubuntu Server administration
- OpenSSH configuration
- Nginx web server deployment
- Linux user and permission management
- Network troubleshooting
- Tailscale secure remote access
